### R01 · 音效完全缺失

- **scene**：全片 ｜ **版本**：v4（基线哈希）
- **现象**：`grep -rn "Audio" showcase/src` 无结果；`showcase/public/` 只有 `fonts/`、`shots/`；成片只有一条 AAC 音轨。任务卡 §9 列了 9 个音效（E_TOGGLE_ACTION / E_OPEN_PRESS / E_CLOSE_PRESS / E_MARK_PRESS / E_MARK_SEEN / E_DRAWER_OPEN / E_CLAIMS_SYNC / E_CARD_LAND / E_ZERO）。证据：`ffprobe` 音轨数 = 1。
- **期望**：每次"接触"有声音。作者要保留的选择：不做 whoosh、不做奖励音（风格卡第 4 条）。
- **根因假设**：先把"画面做完"当成交付，声音只到配乐为止；音效素材没找、代码没写。排除"刻意不用音效"——风格卡写明要用接触类声音。
- **修改**：新增 `showcase/public/sfx/`；`scenes.tsx` 内按事件挂 `<Audio>`；音效文件需 CC0 或自制。
- **影响域**：时间轴不变；S04/S05/S07/S06 的动作可信度；混音需重新做响度（音效会抬高峰值）。
- **回归**：S04 21.4、S05 27.0/28.6/33.0/34.8、S06 43.5/45.0、S07 50.4 各点前后 0.3s 逐帧听。
- **实测（2026-11-03）**：自制 7 个音效（`showcase/public/sfx/`，numpy 合成，无第三方版权）；按事件挂 `<Audio>`，共 10 处。局部渲染验证：E_CLAIMS_SYNC 的峰值落在 **8.20s**（偏差 0.00s）。成片音轨为「音乐 + 音效」混合，响度 -17.15 LUFS / TP -1.03 dB。
- **仍未验证**：实际听感（我只有频谱与峰值，没有耳朵）；音效音量是否盖过音乐 —— 需作者试听
- **状态**：implemented

### R12 · 画面闪烁（作者发现）

- **scene**：全片 ｜ **现象**：中间多处闪烁。
- **根因（已定位）**：① 字幕与高亮层用了 `mixBlendMode`，无头 Chrome 在合成层切换时把文字画两遍；② 噪点材质逐帧位移，形成高频抖动。排除依据：去掉 blend、固定材质后，同段最大帧差 74.9 → **0.85**。
- **修改**：去掉全部 `mixBlendMode`（改普通 rgba 叠加）；材质不再逐帧漂移；字幕层加 `translateZ(0)` 稳定图层；两处明暗硬切（6.0s / 54.0s）改为 0.25–0.3s 过黑。
- **实测**：全片逐帧扫描，完全重复帧 191 → **44**；最大帧差 228 → **73.7**（发生在 54.0s 场景切换，有过黑过渡）。**状态**：implemented

- **根因（已量化）**：① 用的是 `open_002/close_002`，频谱重心 **9.8 kHz**，高频过亮；② 声音挂在 28.6s（抽屉滑完的时刻），而滑动从 **27.2s** 开始，整整晚了 1.4 秒。
- **修改**：换成 `scroll_002`（重心 1.5 kHz）并经 3.5 kHz 低通，开/关分别正向与反向；开抽屉的触发点从 28.6 移到 **27.22**（与 spring 起点对齐）；音量按 RMS 校准（点击 -37.7 dBFS / 滑动 -35.5 dBFS）。
- **实测**：声音起点扫描确认 27.00（点击）→ 27.22（滑动）与画面动作一致；白帧 0；整片 -24.09 LUFS / TP -5.90 dB。**状态**：implemented

#### 追加（作者反馈"仍然偏高频、刺耳"）

- **再改**：不做单纯低通（会削得没力），改为 **降调 + 双重低通**：`asetrate×0.55 / ×0.50` → 48kHz → 700/650 Hz 两级低通 → 0.3s 淡入、0.45s 淡出。
- **量化对比**：频谱重心 **9.8k → 940 → 344 Hz**；4 kHz 以上能量占比 **0.16%**；滑动 RMS -33.0 dBFS（与点击 -32.7 持平，不再是持续轰鸣）。
- **实测**：白帧 0；整片 **-24.36 LUFS / TP -5.90 dB**。**状态**：implemented
