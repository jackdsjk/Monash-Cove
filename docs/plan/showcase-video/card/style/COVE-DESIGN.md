## 1. 语法（对象/材质/空间/笔触）

- **对象即像素**：全片的主体永远是真实界面截图，不是重绘的拟物。截图之外的元素（光标、日历格、卡片外壳）必须用同一套材质语言：白底、`1px` 浅边、`6px` 圆角、无渐变、无投影模糊。
- **空间是平的**：不做伪 3D、不做景深、不做透视。唯一允许的"空间"是缩放与位移。
- **两种底色，不是两种风格**：深场 `#121615` 用于情绪段，亮场 `#F5F5F5` 用于产品段。同一套组件在两种底色上出现，靠明度差完成情绪切换。
- **笔触**：没有手绘、没有粒子、没有光效。允许的唯一"装饰"是 60px 半透明网格线（只在 S02 出现，用来表示"日历"这个纸面）。

## 2. 文字

- 单一字族：Noto Sans SC（无衬线），不插入衬线体与手写体。
- 四档字重：正文 400、副行 500、字幕 600、标题 700。不要用 300 制造"高级感"，中文细体在竖屏压缩后会糊。
- 数字一律 `tabular-nums`，避免计数跳动时宽度抖动。
- 字幕最多两行、每行不超过 18 字，底部固定 y∈[1150,1260]。
- 断行按语义意群显式给，不按标点机械切。

## 3. 运动

| 场景 | 曲线 | 理由 |
|---|---|---|
| 元素抽出/飞行 | `power3.inOut` 2.2s | 有质量感的长距离移动，不弹 |
| 卡片展开 | `spring({stiffness:180, damping:26})` | 有物理感的到位，但不过冲 |
| 标签弹入 | `spring({stiffness:260, damping:20})` | 唯一允许的"活泼"，因为它表示新信息出现 |
| 抽屉滑出 | `spring({stiffness:180, damping:26})` | 同卡片，同一套手感 |
| 文字入场 | `power2.out` 0.5s + 遮罩上移 0.2em | 克制，不做逐字发射 |
| 数字滚动 | 线性插值 + `easeOut` 0.8s | 数值必须与图形同源 |

- **禁止**：模糊转场、闪白、镜头震动、逐字随机延迟、粒子。
- 一个动作只允许一条曲线。同一屏里不允许两个不同手感的弹跳同时存在。

## 4. 声音

- 只用"接触类"声音：按下、纸片、抽屉、落定、归零。
- 不用 whoosh、不用 riser、不用低频冲击、不用"叮"的奖励音（会游戏化）。
- 音乐是 Pad / 钢琴 / 弦乐一类的持续型素材，不打鼓。全片只有一个能量高点（S04）。

## 自查

- 这个风格挪到别的产品上还成立吗？——不成立。它依赖 Cove 的具体界面密度与绿主色。这是好事：说明风格是从产品长出来的。
- 有没有"配色像、运动不像"？——运动规则是单独写的（第 3 节），不是从颜色推出来的。
- 有没有偷偷引入第二种视觉语言？——只有一处：S02 的日历格。它用同一套圆角/边框/字号，但确实是界面之外的构件，已在任务卡 R12 里标为待作者判断。
