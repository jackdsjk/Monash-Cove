# Cove 展示片 · BRIEF

## 这支片子要干什么

把一个已经能跑的真实产品（Cove，本地 Web App）做成一条 58 秒的小红书竖版视频，让 Monash 学生看完的第一反应是「我确实需要这个」。

只做一件事：**让人看见真实界面在替人干活**。不讲架构、不讲模型、不讲"AI 驱动"。

## 观众

- 主体：Monash（及同类海外高校）中文学生，尤其担心 due date 和作业要求变更的
- 他们进入前知道：通知散在 Moodle、Ed、邮箱里，经常是刷到最后才发现漏了什么
- 他们要带走：有一个工具把这些收成一份简报，每条结论能点回原文
- 不是给开发者看的，代码和架构一律不出现

## 边界

- **不出现真实个人信息**。演示账号用自己的合成数据，界面里的课程代码可以用真实公开的 unit code（FIT1045、ETW2001），作业内容一律虚构
- **不伪造第三方品牌界面**。不画假的 Gmail / Moodle 外壳；需要展示邮件内容时，用 Cove 自己的"原文摘录"呈现
- **数字必须可追溯**。字幕和界面出现的每一个数字，都要来自同一个展示账号 fixture
- 不吹"省了 90% 时间"这类没有测量依据的结论

## 已定规格

| 项 | 值 |
|---|---|
| 画幅 | 1080 × 1440（3:4 竖版） |
| fps | 30 |
| 总长 | 58 秒 |
| 声音 | 无口播；字幕烧屏 |
| 画风 | Cove 自有设计系统（非 341 风格库，见 `card/style/COVE-DESIGN.md`） |
| 引擎 | Remotion 4.x |

## 关键路径

1. `card/任务卡.md` — 主文档，逐镜分镜与事件表
2. `card/task.json` — 机器可读时间轴
3. `card/music-plan.md` — 四案音乐（只写不生成）
4. `STATUS.md` — 当前阶段与下一步
